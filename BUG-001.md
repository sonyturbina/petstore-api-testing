# BUG-001 — Invalid petId returns 404 instead of 400

## Endpoint

`GET /pet/{petId}`

## Preconditions

Swagger Petstore API is available.

## Steps to Reproduce

1. Send a GET request to `/pet/abc`.
2. Check the HTTP status code.
3. Check the response body.

## Expected Result

The API returns:

`400 Bad Request`

According to the Swagger documentation, an invalid ID should return `400 — Invalid ID supplied`.

## Actual Result

The API returns:

`404 Not Found`

The response body contains a `NumberFormatException` for the value `"abc"`.

## Severity

Minor

## Environment

- API: Swagger Petstore
- Tool: Postman
- Request method: GET
